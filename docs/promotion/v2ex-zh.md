## 正文（V2EX 版，口语化，别像广告）

---

**先说痛点，估计很多人跟我一样：**

手机相册快满了，想备份到电脑。一看可选方案：
- **百度/Google/iCloud 相册**：要么限速要么订阅费，照片还躺在别人服务器上，鬼知道被拿去训练了什么
- **immich / PhotoPrism**：确实好，但得先买台 NAS、装 Docker、配反向代理……我就想让照片到我电脑上而已，为什么要先当半个运维？
- **Syncthing**：同步很稳，但同步完就是一堆文件夹，没有时间线、没有地图、没有"相册"的感觉
- **LocalSend / 快牙**：发一次文件可以，但它不会天天自动帮我备份相册

所以我自己写了一个：**Uncloud**。

**一句话：手机扫个码和电脑配对，之后相册通过家里 Wi-Fi 自动流到电脑上，能按时间线看，也能当文件管理器用。全程不经过任何云。**

几个点：

- **无云、无账号、无服务器**：不用注册，不用 Docker，不用买 NAS。手机电脑在同一 Wi-Fi 下直连
- **相册 + 文件一体**：不只是照片，任意文件都能跨设备浏览互传
- **本地 AI（在做）**：重复照片检测、人脸分组全部在端侧跑，一个像素都不上传
- **数据可验证**：传输带 SHA-256 校验，代码全开源（Apache-2.0）

**技术栈**（给 V2 友们看的）：
- 核心引擎：零依赖 Node.js（一个 npm 包都没装，`node bin/uncloud.js demo` 直接跑通回环传输）
- App：Flutter，一套代码打 Android/iOS/Windows/macOS/Linux
- 协议：UDP 组播发现 + 扫码配对（ed25519 设备身份）+ TCP 直传
- 界面默认英文，可在设置里一键切中文

**目前进度**：v0.1 核心引擎和 CLI 已能跑（30 个测试全过），App UI 已完成。传输加密和自动备份在 v0.2。

**GitHub**：https://github.com/yniantongtian-oss/uncloud

一个人做的，肯定有很多考虑不周的地方。想听听大家的意见：
1. 你们会为了"不用云"接受"手机和电脑必须在同一 Wi-Fi"这个限制吗？
2. 自动备份和端到端加密，你们更想要哪个先做？
3. 还有什么"被云绑架"的场景想被解决？

欢迎拍砖，更欢迎 PR。Star 一个就当支持了 🙏
